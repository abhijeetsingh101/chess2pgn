How it works

  1. Upload a PDF of a puzzle book, scanned pages, phone photos, or app screenshots.
  2. Review each recognised board next to the original. Fix any piece, and set who is to move.
  3. Optionally type the solution in normal notation (e.g. 1. Qxf7+ Kxf7 2. Bc4+). It is checked for legality.
  4. Download one PGN with every puzzle, ready for Lichess Studies, ChessBase, SCID, etc.
